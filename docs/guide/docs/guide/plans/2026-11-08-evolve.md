## Proposed Why card

This replaces the spec's Why card only after author approval. Source references below refer to the target checkouts.

### Problem

Managing work, personal, and client accounts by manually switching configuration directories can mix conversations, memory, or billing. Some related accounts also need to continue the same conversations while other accounts must stay separate. (`aprofile:README.md:7-9,112-127`.)

### Outcome

The reader can launch each account with a named wrapper, choose how much setup it reuses, and keep history isolated or explicitly share it with profiles of the same supported harness. The selected wrapper uses that profile's login, endpoint, and model. (`aprofile:README.md:25-48,112-140`.)

### Components

aprofile manages named accounts/configurations of coding tools. Claude Code is a terminal coding tool that works on a codebase through natural language. Codex CLI is OpenAI's locally running coding agent. OpenCode is an open source AI coding agent. Pi is a minimal, extensible agent harness. (`aprofile:README.md:3-5`; `claude-code:README.md:7`; `codex:README.md:1`; `opencode:README.md:10`; `pi:README.md:13-17`.)

### Fit

aprofile prepares each profile's configuration and launcher on sync. Share levels govern reused setup. A separate, optional history-group membership links designated history entries to one store for that harness. The built-in home group uses the default setup's history; custom groups use an aprofile-managed store. (`aprofile:README.md:32-48,112-142,233-245`; `aprofile:internal/cli/group.go`; `aprofile:internal/history/`.)

### Why this combination

Users can keep unrelated accounts separate while letting selected profiles continue one another's conversations, without making their logins shared. History-group membership is independent of the share level. (`aprofile:README.md:112-140`; `aprofile:internal/harness/builtin/`.)

### Status and limits

aprofile runs on Linux/macOS and builds from source with the recorded Go minimum. History groups are supported for Claude Code, Codex, and Pi; OpenCode does not support them. Running one conversation simultaneously through multiple members can interleave its transcript. This feature does not convert conversations between harnesses. (`aprofile:README.md:11-23,112-142,284-286`; `aprofile:go.mod`; `aprofile:internal/cli/group.go`; `aprofile:internal/harness/builtin/`.)
